# Stock Trading Platform 📈

A Java-based Stock Trading Platform that simulates basic stock market operations.  
The project allows users to view market stocks, buy and sell stocks, manage portfolios, track transactions, and calculate profit/loss using Object-Oriented Programming concepts.

## Features 🚀

- View available market stocks
- Buy stocks and manage holdings
- Sell stocks from portfolio
- View current portfolio details
- Calculate profit/loss
- Update stock prices
- Maintain transaction history
- File handling for storing transaction data

## Technologies Used 💻

- Java
- OOP Concepts
- Java Collections
- File Handling
- Maven
- IntelliJ IDEA
